# Карточки

Личное приложение для изучения слов с интервальным повторением (FSRS). Работает как PWA: ставится на телефон
с главного экрана, работает офлайн, новые карточки подтягиваются сами при открытии.

## Как добавлять карточки

Скинуть Claude фото, скрин или список слов и сказать, куда положить («лекция 7», «тема: врач»).
Claude соберёт карточки в `public/decks/`, проверит сборку и запушит. Vercel задеплоит за минуту.

Формат карточек и структура папок описаны в [CLAUDE.md](CLAUDE.md).

## Режимы

- **Микс** — всё вперемешку; новое слово сначала учится на узнавание, потом на вспоминание.
- **PL → RU / RU → PL** — классические карточки.
- **Ввод** — пишешь слово сам; ошибка только в диакритике считается «трудно».
- **На слух** — слушаешь и записываешь.

Узнавание и вспоминание планируются раздельно. Прогресс хранится на устройстве; копию можно сохранить в настройках.

## Разработка

```
npm install
npm run dev      # собирает manifest колод и запускает Vite
npm run build    # проверка колод + типы + сборка
```
